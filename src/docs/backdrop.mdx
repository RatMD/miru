# Backdrop

```vue
<Backdrop :visible="menuOpen" :blur="false" />
<Backdrop :visible="menuOpen" blur="lg" />
<Backdrop
    :visible="menuOpen"
    blur="lg"
    faded
    :origin="{ x: menuCenterX, y: menuCenterY }"
    color="rgb(0 0 0 / 0.1)"
    interactive
    @click="menuOpen = false" />
```

`blur` accepts false, true (12px), sm (4px), default (12px), lg (20px), xl (32px), or a pixel number.
`faded` applies the HL Portal profile/view-switcher radial mask: strongest around `origin`, then a
gradual blend back to the sharp page toward the farthest corner. The mask fades both tint and blur;
it does not interpolate a separate blur radius for each pixel. Without backdrop-filter support,
the tint still provides a backdrop.

Fixed layers use viewport coordinates. Use `position="absolute"` inside a positioned container
and subtract the container's bounds from the trigger bounds when supplying pixel coordinates.
Percentage/string origins work too; the default is centered. The Popover story demonstrates a
trigger-relative origin and live positioning on resize/scroll with the existing VueUse helpers.

Backdrop stays decorative and pointer-transparent by default. `interactive` enables click events;
the host controls visibility. Keep menu/dialog content and its active trigger above the backdrop.
It does not teleport, lock scrolling, trap focus or implement Escape. Use the existing Dialog/Sheet/
Popover primitives for those behaviors. The visibility transition respects reduced motion.
