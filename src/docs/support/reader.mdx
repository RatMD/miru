# reader

Read a browser File as a data URL, text or ArrayBuffer.

**Runtime:** Browser.

## Example

```ts
import { reader } from '@rat.md/miru/support';
const file = new File(['example'], 'example.txt', { type: 'text/plain' });
const text = await reader<string>(file, 'text');
```

Modes: data (default), text and buffer. FileReader errors and aborts reject the promise.
