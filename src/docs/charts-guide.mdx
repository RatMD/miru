# ApexCharts

ApexChart adapts apexcharts and vue3-apexcharts without requiring global plugin
registration. Chart code loads after mount, keeping server imports safe. The
Line, Bar and Donut stories demonstrate axis and non-axis series.

```vue
<script setup lang="ts">
import { ApexChart, CardChart } from '@rat.md/miru';
import type { ApexOptions, ApexAxisChartSeries } from '@rat.md/miru';
const props = defineProps<{ title: string; emptyLabel: string; series: ApexAxisChartSeries }>();
const options: ApexOptions = {
    xaxis: { categories: ['1', '2', '3'] },
    stroke: { curve: 'smooth' },
};
</script>
<template>
    <CardChart :title="title" :empty="series.length === 0" :empty-label="emptyLabel">
        <ApexChart type="area" :height="300" :series="series" :options="options" />
    </CardChart>
</template>
```

Defaults derive colors, text and grid from --ui-\* tokens and follow ancestor
class/style/data-theme changes. Explicit options override these defaults, including
colors, toolbar, theme and tooltips. Supply translated series names, categories,
formatters and accessible labels. Upstream chart attributes and events are forwarded.
For imperative APIs, use the upstream chart events to obtain its chart context.

CardChart preserves the original chart-card content slot and empty state; it
can also contain a chart from another renderer. Both chart dependencies are
installed with the package. Their upstream licensing requirements still apply.
