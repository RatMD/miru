# DataTable adapters

Normalize backend data at the boundary. Columns, selection and rendering then use the same `ListPayload<T>`. Import the helpers and types below from `@rat.md/miru`.

## Laravel

`adaptLaravelPagination(paginator, path?)` accepts the snake_case length-aware paginator (`data`, `current_page`, `last_page`, `per_page`, `total`). It fills Miru's `first_page`, ranges and missing page URLs. `adaptLaravelList` also normalizes the surrounding state:

```vue
<script setup lang="ts">
import { computed } from 'vue';
import { DataTable, adaptLaravelList } from '@rat.md/miru';
import type { LaravelListPayload, DataTableColumnDef } from '@rat.md/miru';
type Item = { id: string; name: string };
const props = defineProps<{ payload: LaravelListPayload<Item> }>();
const list = computed(() => adaptLaravelList(props.payload));
const columns: DataTableColumnDef<Item>[] = [{ accessorKey: 'name', header: 'Name' }];
</script>

<template><DataTable table-key="laravel-items" :list="list" :columns="columns" /></template>
```

The wrapper is `{ results: paginator, config, filters, state? }`. Your app supplies `config` (available columns/filters/actions). A Laravel API Resource using separate `data`, `meta`, `links` needs an explicit mapping; cursor pagination has no total/last-page contract and needs a different paging UI.

## AdonisJS / Lucid

Lucid pagination uses `{ data, meta: { currentPage, lastPage, perPage, total } }`. Wrap it in `{ results, config, filters, state? }` and pass `data-format="lucid"`:

```vue
<script setup lang="ts">
import { DataTable } from '@rat.md/miru';
import type { LucidListPayload, DataTableColumnDef } from '@rat.md/miru';
type Item = { id: string; name: string };
const props = defineProps<{ payload: LucidListPayload<Item> }>();
const columns: DataTableColumnDef<Item>[] = [{ accessorKey: 'name', header: 'Name' }];
</script>

<template>
    <DataTable
        table-key="lucid-items"
        :list="props.payload"
        :columns="columns"
        data-format="lucid" />
</template>
```

For manual normalization use `adaptLucidPagination` or `adaptLucidList`, then keep the table's default format. Lucid state uses `perPage`, `orderBy` and lowercase `order`; callbacks still receive canonical `ListState` with `per_page`, `order_by` and uppercase `order`.

Both examples above use the host's Inertia transport. Add `queryHandler` from the [JSON example](/reference/data-table-guide) for a plain API. Backend framework and client transport are separate choices.

## Custom response and query adapter

A typed adapter can live in your application. It may map any API response into Miru's list contract. Apply `adapter.normalize(response)` before binding `list`.

```ts
import { adaptLaravelPagination } from '@rat.md/miru';
import type { DataTableAdapter, ListPayload } from '@rat.md/miru';

type Item = { id: string; name: string };
type ApiPage = { items: Item[]; count: number; page: number; pageSize: number };
const config: ListPayload<Item>['config'] = {
    searchable: ['name'],
    sortable: ['name'],
    filters: {},
    actions: [],
};

const adapter = {
    normalize(source: ApiPage): ListPayload<Item> {
        return {
            results: adaptLaravelPagination({
                data: source.items,
                total: source.count,
                current_page: source.page,
                per_page: source.pageSize,
                last_page: Math.max(1, Math.ceil(source.count / source.pageSize)),
            }),
            config,
            filters: {},
            state: {
                page: source.page,
                per_page: source.pageSize,
                order_by: 'name',
                order: 'ASC',
                search: null,
            },
        };
    },
    serializeQuery(state, filters) {
        return {
            page: state.page,
            limit: state.per_page,
            sortBy: state.order_by,
            sortDir: state.order.toLowerCase(),
            filters: JSON.stringify(filters),
        };
    },
} satisfies DataTableAdapter<ApiPage, Item>;
```

Preserve the current filters/sort state when replacing a list after a request. Use returned metadata when the server clamps a page or changes its size. An adapter maps data; it does not validate an untrusted JSON response or authorize actions.

For Inertia, bind `:query-serializer="adapter.serializeQuery"`. For a custom `queryHandler`, call it yourself before fetching and normalize the result afterward. `queryHandler` replaces the built-in serializer/transport path.

## Endpoint-specific Lucid queries

Lucid defines pagination metadata, not your endpoint's parameter names. Customize the built-in serializer when needed:

```ts
import { serializeLucidQuery } from '@rat.md/miru';
import type { ListState } from '@rat.md/miru';
const serialize = (state: ListState, filters: Record<string, unknown>) =>
    serializeLucidQuery(state, filters, { perPageKey: 'limit' });
```

Bind it as `querySerializer` for Inertia, or call it in your fetch handler. `serializeFilters` can encode ranges or arrays for your endpoint. Laravel endpoints can use their own serializer in exactly the same way.
