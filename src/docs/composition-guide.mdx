# Connected controls and responsive filter bars

## ButtonGroup

ButtonGroup connects independent buttons. It does not replace ToggleGroup, does
not own selected state and does not override its children's variant, size or click
handlers. Set orientation to horizontal (default) or vertical. Give the group an
accessible label and each icon-only button an accessible name. Tab still visits
individual enabled buttons. Use consistent child sizes for a continuous border.

```vue
<ButtonGroup :label="labels.actions">
  <Button variant="outline" @click="save">{{ labels.save }}</Button>
  <Button variant="outline" icon-only :aria-label="labels.remove" @click="remove">
    <IconTrash />
  </Button>
</ButtonGroup>
```

## FilterBadges and DataTable

FilterBadge and FilterBadges accept size=sm/default/lg (24/28/32px). Removable chips use a separate X button and divider; their label is not a remove action. The dots badge renders a 16px icon.

FilterBadges accepts localized items shaped as key, label, optional value,
selected and removable. DataTable uses removable chips; Command uses both
available and selected type chips. A remove event requests removal, while select
requests an available option. The host updates its items/model.

The visible prefix is measured against actual available width. A dots badge appears
when the items cannot fit; its Popover exposes all items so even very long filters
remain operable. ResizeObserver recalculates the prefix after container/text size
changes. Invisible inert measurement nodes never enter the keyboard sequence and
are clipped to avoid page overflow.

DataTable now connects Filter with a FilterOff icon button only while applied
filters exist. Applied search is represented as a chip too. Clear removes all
filters/search; an individual X removes one key. The same queryHandler/Inertia
contract remains responsible for updating ListPayload. Both default and compact
variants use this shared behavior. DataTable's Active Filter Overflow example
starts with three active filters and adapts when the preview narrows.

```vue
<FilterBadges :items="activeFilters" @remove="removeFilter" />
```

## Command and CommandDialog

The command UI is application-independent. Storybook lists Command under Data & Structure with a modal default and a separate Inline example. It supplies Listbox
keyboard behavior, grouped results, type-filter bubbles and the same dots Popover.
It does not embed application routes, permissions, server requests or a global hotkey.
The host localizes labels, loads items and handles select. Optionally register the
Alt+F shortcut in the host and bind open to CommandDialog.

```ts
import type { CommandItem, CommandFilter } from '@rat.md/miru';
const items: CommandItem[] = [
    {
        value: 'project-1',
        label: labels.project,
        description: labels.details,
        type: 'projects',
        group: labels.workspace,
        keywords: ['MIRU'],
    },
];
const filterOptions: CommandFilter[] = [{ value: 'projects', label: labels.projects }];
```

```vue
<Command
    v-model:query="query"
    v-model:filters="types"
    :items="items"
    :filter-options="filterOptions"
    :placeholder="labels.search"
    @select="openItem" />
<CommandDialog
    v-model:open="open"
    v-model:query="query"
    v-model:filters="types"
    :items="items"
    :filter-options="filterOptions"
    :title="labels.title"
    :description="labels.description"
    @select="openItem" />
```

Empty types means all types. Filtering matches all query words against label,
description and keywords. Results preserve incoming order and groups; disabled
items cannot be selected. Arrow keys navigate, Enter emits select, and the dialog
closes on selection unless closeOnSelect=false. For remote search, watch query
and types, update items/loading and handle stale requests in the host.

## Drawer

Drawer is based on Reka Drawer, while Sheet is based on Dialog. Responsive mobile surfaces now use Drawer; explicit desktop/side Sheet primitives remain available.
It uses the installed reka-ui Drawer primitives; no extra drawer package is needed.
Down is the default swipe direction and renders at the bottom. Its default snapPoints are [0.5,0.9], starting at 0.5. The surface stays anchored at the viewport bottom while growing toward the 90% stop. Content includes
a handle and close control by default. DrawerContent maxHeight defaults to 90dvh, contentSize to 5xl (1024px), and scrollable to true. It uses a centered frame and ScrollArea; header/footer slots stay visible. Title and description remain required for
accessible composition. The handle is a drag affordance; a keyboard-accessible
Close button is always available unless intentionally replaced by the host.

```vue
<Drawer v-model:open="open">
  <DrawerTrigger as-child><Button>{{ labels.open }}</Button></DrawerTrigger>
  <DrawerContent>
    <template #header><DrawerHeader><DrawerTitle>{{ labels.title }}</DrawerTitle>
      <DrawerDescription>{{ labels.description }}</DrawerDescription></DrawerHeader></template>
    <div class="min-h-0 flex-1 overflow-y-auto px-6 pb-6"><YourContent /></div>
    <template #footer><DrawerFooter><DrawerClose as-child><Button variant="outline">{{ labels.close }}</Button>
    </DrawerClose></DrawerFooter></template>
  </DrawerContent>
</Drawer>
```

swipeDirection also supports up, left and right. showHandle=false hides the visual
handle; gestures still work through the drawer primitive. snapPoints and
v-model:snapPoint use Reka's fraction/pixel/string contract. For example, use
snapPoints=[0.4,0.9], a defaultSnapPoint of 0.9 and maxHeight="90dvh". The Snap Points, Expanded and Custom Height stories demonstrate this. Focus trapping, Escape/outside dismissal,
focus return and reduced-motion styles are preserved. Scrollable content can be
scrolled before a dismiss gesture; the primitive coordinates scrolling and swipe.

## AspectRatio

AspectRatio follows its parent's width. square (1:1) is the default; presets also
include video (16:9), photo (4:3), portrait (3:4) and cinema (21:9). A positive
numeric ratio takes precedence over the preset; non-finite/non-positive values
fall back to 1. It controls layout, not image loading or cropping.

```vue
<div class="w-full max-w-xl">
  <AspectRatio preset="video"><img :src="imageUrl" :alt="labels.image"
    class="size-full object-cover" /></AspectRatio>
</div>
<AspectRatio :ratio="2.5"><YourContent /></AspectRatio>
```
