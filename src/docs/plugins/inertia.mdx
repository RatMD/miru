# inertia

Connect Miru to an existing Inertia app.

```ts
import { createApp, h } from 'vue';
import { createInertiaMiru } from '@rat.md/miru/plugins/inertia';

// Inside your Inertia setup({ el, App, props, plugin }) callback:
const miru = createInertiaMiru();
createApp({ render: () => h(miru.wrap(App), props) })
    .use(plugin)
    .use(miru)
    .mount(el);
```

Import `createApp` and `h` from Vue in your setup file. The adapter reads reactive locale and page toasts from `page.props.app` when you have not supplied explicit sources. Your host owns Inertia setup, routes and page data. Mount UiRoot only once; the adapter adds no navigation listeners.
