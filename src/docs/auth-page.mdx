# AuthPage

Import `AuthPage` from `@rat.md/miru` or `@rat.md/miru/layouts`.

```vue
<AuthPage title="Welcome back" description="Sign in to your workspace" image="/images/auth.webp">
    <template #brand><AppLogo /></template>
    <LoginForm />
    <template #footer><LegalLinks /></template>
</AuthPage>
```

`variant="split"` is the default side panel/image layout. `panelSide="right"` reverses its desktop position.
`variant="card"` centers the panel over the visual. `panelWidth`, `maxWidth` and `height` accept pixel
numbers or CSS lengths. `framed=false` removes the outer frame; `fullHeight=false` allows embedding.

On small screens the split image moves above the form. `hideVisualOnMobile` hides that image entirely.
The form stays in document flow and can grow when validation adds messages or a mobile keyboard opens.
The layout does not change global html/body styles or install authentication/router behavior.

Use an application image URL, replace the `visual` slot, or keep the included theme-aware SVG artwork.
`imageAlt` defaults to an empty decorative description. `visual-overlay` can provide a translated
testimonial or headline; `header`, `brand`, `footer` and the default form slot remain host-owned.

The examples follow the split/card structure used by the SHODAN and Spottle applications, without
copying their brand assets, application stores or authentication requests.
