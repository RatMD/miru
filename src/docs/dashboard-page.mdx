# DashboardPage

A shared shell for a Cockpit-style expanded sidebar and a Portal-style icon rail. Import from
`@rat.md/miru` or `@rat.md/miru/layouts`. It composes navigation and page structure, while the host
owns routing, access checks, authentication, data fetching and menu persistence.

```vue
<DashboardPage
    v-model:collapsed="sidebarCollapsed"
    v-model:mobile-open="mobileMenuOpen"
    :navigation="groups"
    :breadcrumbs="breadcrumbs"
    sidebar-tone="dark"
    surface="inset"
    scroll-region
    @navigate="navigate">
    <template #brand="{ collapsed }"><AppLogo :compact="collapsed" /></template>
    <template #header><WorkspaceSearch /></template>
    <template #actions><Notifications /><ProfileMenu /></template>
    <RouterView />
    <template #footer><AppVersion /></template>
    <template #app-bar><FloatingAppBar label="Quick actions"><!-- host actions --></FloatingAppBar></template>
</DashboardPage>
```

## Presentation

- `collapsed`: controlled icon rail; expanded and rail widths use `sidebarWidth` and `railWidth`.
- `sidebarTone`: `surface`, `muted` or `dark`; `surface`: `inset` or `flush` content framing.
- `headerSize`: `sm`, `default` or `lg`; `stickyHeader` defaults to true.
- `padding`: `none`, `sm`, `default` or `lg`; `contentWidth` optionally limits the content width.
- `scroll="content"`: a bounded viewport with independent navigation/content scrolling.
- `scroll="page"`: normal document scrolling with a sticky desktop sidebar.
- `sidebar=false`: omit desktop and mobile navigation, keeping the header and content shell.
- `scrollRegion`: adds the host integration attribute to the actual native scroll container.

The Cockpit example uses an expanded dark sidebar and inset content. The Portal example starts
collapsed with a muted rail, taller header, flush content and a mobile action bar. All options can
be combined rather than being coupled to a named application preset.

## Navigation and routing

Pass groups with stable `id`, optional `label`/`boxed`, and `items`. Items have `id`, translated
`label`, optional icon component, `href`, `active`, `disabled`, `badge` and nested `children`.
Child groups expand inline; in the icon rail they open an accessible Popover.

The host determines `active` and filters its navigation for permissions. Plain anchors work by
default. `linkComponent` accepts an href-compatible adapter such as Inertia Link; Vue Router can
be wrapped in a small adapter that maps href to to. For entirely custom navigation, replace the
`navigation` slot (`collapsed`, `closeMobile`).

`navigate(item, event)` lets the host prevent the native click and route itself. Selecting a leaf
closes the mobile menu; disabled entries never emit navigation. The mobile Sheet handles Escape,
focus trapping and focus return. Resizing to desktop closes an open mobile menu.

## Slots

`brand`, `navigation` and `sidebar-footer` receive `collapsed` (false in the mobile menu).
`header`, `actions`, `toolbar`, `breadcrumbs`, `banner`, `footer`, `app-bar` and `overlays` let
each application keep its existing services and controls. Install UiRoot once above the shell
when Toast/page-toast hosting is needed; the layout does not add a second provider.
