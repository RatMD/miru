# DataTable

Use the same table with Laravel, AdonisJS/Lucid or your own API. Normalize responses to `ListPayload`, then choose your transport. The UI does not need an Adonis or Laravel runtime.

| Source                         | How to connect it                                                                      |
| ------------------------------ | -------------------------------------------------------------------------------------- |
| Miru `ListPayload`             | Pass `list` directly.                                                                  |
| Laravel length-aware paginator | Use `adaptLaravelPagination` or `adaptLaravelList`, then pass the result.              |
| AdonisJS/Lucid                 | Use `data-format="lucid"` with `LucidListPayload`, or normalize with `adaptLucidList`. |
| Custom API                     | Write a `DataTableAdapter` and pass its normalized list.                               |

See [backend adapters](/reference/data-table-adapters) for the response shapes and copyable mappings. A raw paginator needs your filters/configuration around it; the table does not infer permissions or available filters.

## A table with a JSON endpoint

This component takes the first normalized page as a prop. `/api/projects` must return the next `ListPayload`; adapt its response if your API uses another shape.

```vue
<script setup lang="ts">
import { shallowRef, ref } from 'vue';
import { DataTable } from '@rat.md/miru';
import type { ListPayload, ListState, DataTableColumnDef } from '@rat.md/miru';

type Item = { id: string; name: string };
const props = defineProps<{ initialList: ListPayload<Item> }>();
const list = shallowRef(props.initialList);
const loading = ref(false);
const error = ref('');
const columns: DataTableColumnDef<Item>[] = [{ accessorKey: 'name', header: 'Project', size: 0 }];

async function query(state: ListState, filters: Record<string, unknown>) {
    loading.value = true;
    error.value = '';
    try {
        // Choose parameter names that your endpoint accepts.
        const params = new URLSearchParams({
            page: String(state.page),
            limit: String(state.per_page),
            sort: state.order_by,
            direction: state.order.toLowerCase(),
            filters: JSON.stringify(filters),
        });
        const response = await fetch('/api/projects?' + params);
        if (!response.ok) throw new Error('Could not load projects.');
        list.value = await response.json();
    } catch (cause) {
        error.value = cause instanceof Error ? cause.message : 'Could not load projects.';
    } finally {
        loading.value = false;
    }
}
</script>

<template>
    <p v-if="error" role="alert">{{ error }}</p>
    <DataTable
        table-key="projects"
        :list="list"
        :columns="columns"
        :loading="loading"
        :query-handler="query" />
</template>
```

`queryHandler(state, filters)` receives normalized state for every backend. Update the bound list after each request; the table does not fetch or filter all rows itself. Configure `list.config.searchable` and `sortable` to enable those controls. Your endpoint must validate sort columns, filters and page sizes.

## Inertia or manual transport

Without `queryHandler`, the table uses your host's Inertia router. `querySerializer` customizes that Inertia query; Lucid has its own configurable default serializer. A custom `queryHandler` owns serialization itself, so call your adapter's serializer inside it if needed.

For JSON bulk actions or reordering, also supply `bulkActionHandler` / `moveHandler`. Row actions may use `execute` callbacks. Each request stays under your application's control.

## Mobile and state

Use `meta.mobileHidden` for secondary columns and `meta.mobileSize` for compact widths. Set `size: 0` on the main text column to use remaining space. Long content may still scroll horizontally.

Give each table a unique `tableKey`; column preferences persist separately. `v-model:selected` controls selection and `loading` blocks interactions while your request runs.
