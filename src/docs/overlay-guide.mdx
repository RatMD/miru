# Responsive overlays

Use **Dialog**, **Drawer** and explicit side **Sheet** panels for low-level composition. Use **Overlay** when one surface must become a bottom Drawer below 768px and a centered Dialog on tablet/desktop. Open state survives breakpoint changes. The header and footer stay visible while the body scrolls. Loading blocks Escape, outside clicks and close controls; programmatic changes to `open` remain possible.

The former `DialogResponsive`, `DialogChoice`, `DialogNotice`, `DialogFrame` and `DialogAction` exports have been removed. Replace them with `Overlay`, `OverlayChoice`, `OverlayNotice` and `OverlayAction`. Data Table confirmations use OverlayChoice internally. Applications own data fetching, translations and authorization.

## Custom content

```vue
<Overlay v-model:open="open" :title="labels.title" :description="labels.description">
  <template #trigger>
    <OverlayTrigger as-child><Button>{{ labels.open }}</Button></OverlayTrigger>
  </template>
  <MyContent />
  <template #footer="{ close }">
    <div class="flex justify-end"><Button variant="outline" @click="close">{{ labels.close }}</Button></div>
  </template>
</Overlay>
```

Use `flush` for edge-to-edge bodies, `size` for a shared DialogSize width, and `fixedFrame` for a 90dvh frame. Setting `dismissible=false` blocks ambient dismissal and removes the header close control; an application action can still change `open`. Provide a meaningful title/description in the current application locale.

## Confirmations and notices

```vue
<OverlayChoice
    v-model:open="open"
    :title="labels.deleteTitle"
    :description="labels.deleteDescription"
    variant="danger"
    :loading="saving"
    :error="error"
    :primary="{ label: labels.delete }"
    @confirm="removeRecord" />
<OverlayNotice
    v-model:open="noticeOpen"
    :title="labels.savedTitle"
    :description="labels.savedDescription" />
```

OverlayChoice keeps confirmations open by default. For async operations, clear old errors, set loading, await the host request, then close only on success. Use `closeOnConfirm` for synchronous actions. Actions use the `OverlayAction` type (label, variant, size, icon, disabled). The secondary action emits cancel. Notice supports description, default and actions slots.

## Log/details inspector

```ts
import type { CodeSection } from '@rat.md/miru';

// Resolve labels through your application's translator.
const sections: CodeSection[] = [
    { id: 'request', label: labels.request, language: 'json', value: requestPayload },
    { id: 'response', label: labels.response, language: 'html', value: responseHtml },
    { id: 'trace', label: labels.trace, language: 'text', value: stackTrace },
];
```

```vue
<OverlayDetails
    v-model:open="detailsOpen"
    v-model:active-tab="activeTab"
    :title="labels.title"
    :description="labels.description"
    :sections="sections"
    :loading="loading"
    :error="error"
    max-height="min(55dvh,32rem)" />
```

Tabs appear only for multiple sections; ids must be stable and unique. Changing the section list resets an invalid selection to its first entry. JSON values may be objects or JSON strings; other strings use html or text explicitly. CodePanel is also exported independently with `value`, `language`, `format`, `lineNumbers`, `maxHeight` and `label` props.

Formatting uses lazy-loaded [Prettier standalone](https://prettier.io/docs/browser). It never renders HTML as markup. Invalid syntax is shown unchanged with a localized hint. Copy writes the displayed source without line numbers, and reports success only after the clipboard operation. Set `format=false` to preserve the source exactly or avoid formatting very large payloads. Object values are serialized as JSON; BigInt becomes a string and actual cycles become `[Circular]`.

## Surface sizes

DialogContent accepts size (default lg / 512px). Overlay defaults to 2xl / 672px,
OverlayChoice and OverlayNotice to lg / 512px, and OverlayDetails to 5xl / 1024px.
Use sm, md, lg, xl, 2xl, 3xl, 4xl, 5xl, 6xl, 7xl or full. These sizes apply to the
desktop Dialog. The mobile presentation remains a bottom Drawer.

widthClass remains a custom width override. Overlay's legacy wide=true selects
6xl; set wide=false when controlling width through size. fixedFrame affects
height, independently of size. All default examples preserve 16px viewport gutters.

```vue
<Overlay size="4xl" :title="labels.title" v-model:open="open" />
<OverlayChoice size="xl" :title="labels.title" :description="labels.description" />
<OverlayDetails size="6xl" :title="labels.title" :sections="sections" />
```

Mobile Drawer defaults to 50% with an expanded 90% stop. Overlay exposes drawerSnapPoints and drawerMaxHeight; loading/nondismissible overlays cancel swipe dismissal. The mobile body uses ScrollArea while header/footer stay visible.
