# useFloatingAppBar

Provide a shared app bar in a parent, then add temporary page actions in descendants.

```ts
// Parent layout setup:
import { provideFloatingAppBar } from '@rat.md/miru/composables';
const bar = provideFloatingAppBar();
```

Use the controller in a child setup:

```ts
import { useFloatingAppBar } from '@rat.md/miru/composables';
import { h } from 'vue';
const SaveIcon = () => h('span', { 'aria-hidden': 'true' }, '✓');
const bar = useFloatingAppBar();
const release = bar.push({
    variant: 'primary',
    primary: {
        key: 'save',
        label: 'Save',
        icon: SaveIcon,
        onClick: () => console.log('Save requested'),
    },
});
release(); // Remove only this layer; safe to call twice.
```

The controller exposes `current`, `transitionKey`, `depth`, `set`, `push`, `pop`, `clear` and `reset`. `useFloatingAppBar(source)` installs a page layer on mount and releases it on disposal. See [AppBar](/reference/floating-app-bar).
