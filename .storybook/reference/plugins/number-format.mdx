# number-format

Display a number using `Intl.NumberFormat` with optional precision, grouping, percentage, unit, currency or compact-notation options. Works on text-only elements and component roots such as `BadgePart` or `TableCell`.

[Read the full documentation on miru.at ↗](https://miru.at/docs/plugins/number-format)
