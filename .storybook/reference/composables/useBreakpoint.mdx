# useBreakpoint

The composable returns computed matches, width, height, orientation, current, ready and breakpoints. `resolve(name)` resolves a named threshold, `between(min,max)` evaluates a range, and greaterOrEqual/ smaller return computed booleans. Pass a reactive getter for live options: `useBreakpoint(() => ({ min: minimum.value, breakpoints: custom.value }))`.
